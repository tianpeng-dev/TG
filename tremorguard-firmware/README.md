# TremorGuard 震颤检测手环固件

基于 **Seeed Studio XIAO ESP32C3** + **MPU6050** 的六轴运动数据采集固件，适用于帕金森震颤检测手环产品原型。

固件通过 I2C 读取 MPU6050 三轴加速度（g）与三轴角速度（°/s），经校准后以 100Hz 采样 + 5Hz 输出（窗口聚合，人类可读结构化报告）从 UART（USB-CDC，115200 波特率）实时输出。

---

## 一、硬件清单

| 元件 | 型号 | 说明 |
|------|------|------|
| 主控 | Seeed Studio XIAO ESP32C3 | RISC-V 单核 160MHz，集成 USB-CDC |
| 传感器 | MPU6050 | 六轴（三轴加速度 + 三轴陀螺仪），I2C 接口 |
| 电源 | 3.3V | XIAO 板载稳压，可直接由 USB 供电 |

## 二、接线说明

MPU6050 与 XIAO ESP32C3 通过 I2C 连接：

```
XIAO ESP32C3          MPU6050
─────────────         ─────────
3V3   ─────────────── VCC        (注意：多数 MPU6050 模块支持 3.3V/5V，接 3V3 更安全)
GND   ─────────────── GND
D4 (GPIO6) ────────── SDA        (I2C 数据线)
D5 (GPIO7) ────────── SCL        (I2C 时钟线)
                       AD0 ── GND (使设备 I2C 地址为 0x68)
```

> **注意：** XIAO ESP32C3 的 I2C 引脚是 **D4=GPIO6 (SDA)** 与 **D5=GPIO7 (SCL)**。
> 板上 D6/D7 是 UART TX/RX，**不是 I2C**，请勿接错！

## 四、Arduino IDE 环境配置

### 1. 安装 ESP32 开发板支持

1. 打开 **Arduino IDE → 文件 → 首选项**
2. 在「附加开发板管理器 URL」中添加：
   ```
   https://raw.githubusercontent.com/espressif/arduino-esp32/gh-pages/package_esp32_index.json
   ```
3. 打开 **工具 → 开发板 → 开发板管理器**，搜索 `esp32`，安装 **esp32 by Espressif Systems**（版本 ≥ 2.0.x）

### 2. 选择开发板

打开 **工具** 菜单，按以下配置选择：

| 选项 | 配置值 |
|------|--------|
| 开发板 | `XIAO_ESP32C3`（位于「Seeed Studio XIAO ESP32 Arduino」分类下） |
| Upload Mode | `USB-OTG (TinyUSB)` 或 `UART0 / Hardware CDC` |
| USB Mode | `Hardware CDC and JTAG`（默认） |
| Port | 选择 XIAO ESP32C3 对应的串口/USB 端口 |

> 若开发板列表中无 XIAO ESP32C3，请在开发板管理器中额外安装 **Seeed Studio XIAO ESP32 Arduino** 核心。

### 3. 打开项目

**文件 → 打开**，选择 `tremorguard-firmware/tremorguard-firmware.ino`。
Arduino IDE 会自动加载同目录下的 `MPU6050Driver.h` 与 `MPU6050Driver.cpp`。

> 本固件**不需要**安装任何第三方库（如 Adafruit MPU6050、Jeff Rowberg I2Cdev 等），仅依赖 ESP32 Arduino 核心自带的 `Wire.h` 与 `Arduino.h`。

## 五、编译与烧录

1. 通过 USB-C 数据线将 XIAO ESP32C3 连接至电脑
2. 在 Arduino IDE 中选择正确的端口（**工具 → 端口**）
3. 点击「上传」按钮（→）进行编译与烧录
4. 烧录过程中 XIAO 板载指示灯会闪烁，烧录完成后自动复位运行

## 七、串口输出格式

固件采用**采样与输出解耦**设计：100Hz 高频采样 + 5Hz 低频输出。

| 层级 | 频率 | 间隔 | 作用 |
|------|------|------|------|
| 采样层 | 100 Hz | 10 ms | 读取六轴数据并纳入窗口累加器（保留 4-6Hz 震颤信号） |
| 输出层 | 5 Hz | 200 ms | 打印窗口统计的人类可读结构化报告（人眼舒适区） |

每 200ms 输出一份窗口报告，包含均值/峰值/最新值/震颤强度：

```
--- T=12345ms (12.3s)  窗口=200ms / 20样本 ---
加速度 (g)    |   X       Y       Z
  均值        | 0.012  0.003  1.001
  峰值        | 0.045  0.038  1.023
  最新        | 0.008 -0.002 0.999
角速度 (°/s)  |   X       Y       Z
  均值        | 0.21  -0.15   0.08
  峰值        | 2.34   1.87   0.92
  最新        | 0.12  -0.05   0.03
震颤强度:  加速度峰值向量和 = 0.062 g   |   角速度峰值向量和 = 3.120 °/s
```

| 字段 | 含义 | 用途 |
|------|------|------|
| 时间戳 | 毫秒+秒 | 时间定位 |
| 均值 | 窗口内 ~20 个样本平均 | 反映趋势/姿态 |
| 峰值 | 窗口内绝对值最大 | 反映震颤幅度（关键） |
| 最新 | 窗口最后一个样本 | 实时姿态 |
| 震颤强度 | 三轴峰值向量和 `sqrt(px²+py²+pz²)` | 震颤检测核心指标 |

I2C 读取异常时窗口内会累计失败次数并在报告头显示 `失败N`，全部失败时输出 `[WARN] 本窗口无有效样本`。

每份窗口报告最后还会追加一行 `[NET] …` 状态摘要，一目了然：
```
[NET] SoftAP TremorGuard-A1B2C3  IP=192.168.4.1  STA=待配网
[NET] STA 已连接 IP=192.168.1.55  SSID=MyHomeWiFi
```

## 八、WiFi 配网（SoftAP 模式）

固件内置完整的 **SoftAP + Captive Portal（捕获门户）** 配网流程，使用 ESP32 Arduino 3.0.x 内核自带的 `WiFi / WebServer / DNSServer / Preferences`，无第三方库依赖。

### 8.1 配网触发条件

设备上电后按以下逻辑：
1. 读取 NVS 命名空间 `tremorguard_net` 中保存的配置
2. 若 `provisioned=1` 且 `ssid` 有效 → 进入 STA 连接（最多尝试 3 次，每次 15s 超时）
3. 若未配置 / 所有尝试失败 → 自动开启 SoftAP 配网热点

### 8.2 热点信息

| 项 | 值 |
|----|----|
| SSID | `TremorGuard-<6字符短码>`（如 `TremorGuard-A1B2C3`，短码=MAC 后 3 字节） |
| 加密 | 开放网络（无密码），手机即可连接 |
| 设备 IP | **固定 `192.168.4.1`** |
| 子网掩码 | `255.255.255.0` |
| Captive Portal | 开启：手机连上后会自动弹窗（iOS/Android 系统浏览器） |

> 若浏览器未自动弹出，请手动访问 `http://192.168.4.1`。

### 8.3 网页表单字段与校验规则（前端 + 后端双保险）

| 字段 | 要求 | 校验 |
|------|------|------|
| WiFi 名称 (SSID) | 必填 | 长度 1-32，可通过「扫描」下拉选择 |
| WiFi 密码 | 开放网络留空 / 加密网络必填 | 加密时 8-63 字符（WPA-PSK 规范） |
| 服务器地址 | 必填 | 必须以 `http://` 或 `https://` 开头，如 `http://192.168.1.100:8080` |

### 8.4 配网流程 & 原子写入 NVS（关键机制）

```
用户手机连热点 → 填表单 → 点击「开始连接」
                │
                ▼
  设备以 WIFI_AP_STA 双模式（不关热点）临时尝试连接指定 WiFi
                │
       ┌────────┴────────┐
       ▼                 ▼
   连接成功           连接失败（密码错误/超时/无此SSID）
       │                 │
       ▼                 ▼
① 先原子写 NVS        不改动 NVS
  tremorguard_net:    保留原有凭证
  ssid/password/      回到配网页面并提示错误原因
  server_url → 最后写
  provisioned=1
   │
   ▼
② 关闭热点，切回 WIFI_STA
配网完成 ✓
```

原子语义：**仅当 STA 实际 `WL_CONNECTED` 成功后才写 NVS**，且 `provisioned=1` 最后写入——如果中途断电导致 `provisioned` 缺失，下次启动自动判定为未配网，不会带半写入的坏数据。失败场景下的 NVS 完全不动。

### 8.5 NVS 命名空间 `tremorguard_net`

| Key | 类型 | 说明 |
|-----|------|------|
| `ssid` | String | WiFi SSID |
| `password` | String | WiFi 密码（空=开放网络） |
| `server_url` | String | 服务器地址（`http(s)://host:port[/path]`） |
| `provisioned` | UChar | `1`=已完成配网；缺失或 `0`=未配网 |

> 想强制擦除重配？在 Arduino IDE 菜单选择 **工具 → Erase Flash: All Flash Contents** 后再上传一次固件即可。

### 8.6 测试场景指南

| 场景 | 操作步骤 | 期望结果 |
|------|----------|----------|
| **断电重启恢复** | 完成配网并确认 STA 已连接 → 按 RST 复位或拔插 USB | `[NET] NVS 已恢复: ssid=…` → 跳过配网，数秒内进入 `STA 已连接 IP=…`，无需再打开网页 |
| **错误密码处理** | 在配网页输入正确 SSID 但故意写错密码（少于 8 位或错字符） | 少于 8 位：前端/后端当场拦截；错字符：15s 内前端提示「WiFi 密码错误」。NVS 不被修改，SoftAP 仍开放。 |
| **连接超时策略** | 选择一个根本不存在的 SSID（或把路由器关掉），手动填入然后提交 | 15s × 2 次尝试后提示「TIMEOUT」。NVS 不动，可重新选择网络。 |
| **配网时采样不中断** | 在 SoftAP 配网页面停留 30 秒以上、反复点击扫描 / 提交 / 返回，同时观察串口输出 | 每 1 秒会稳定输出一份震颤窗口报告（`--- T=…`开头），报告中样本数≈100、无长段暂停；最后一行 `[NET] SoftAP …` 正常显示。 |

## 九、传感器参数说明（基于 MPU6050 官方数据手册）

| 参数 | 默认值 | 说明 |
|------|--------|------|
| 采样率 | 100 Hz | `1kHz / (1 + SMPLRT_DIV)`，震颤主频 4–6Hz，满足奈奎斯特定理 |
| 加速度量程 | ±4g | 灵敏度 8192 LSB/g，兼顾动态范围与精度 |
| 陀螺仪量程 | ±500°/s | 灵敏度 65.5 LSB/°/s |
| DLPF | 0x03 | 加速度带宽 44Hz / 陀螺仪带宽 42Hz，滤除高频噪声保留震颤频段 |
| I2C 频率 | 400 kHz | Fast Mode |
| 时钟源 | PLL with X-axis gyro | 比内部 RC 振荡器更稳定 |

如需修改参数，编辑 `MPU6050Driver.cpp` 中 `MPU6050Driver()` 构造函数的 `_cfg` 字段，或通过带参构造函数 `MPU6050Driver(config)` 传入自定义配置。

## 十、常见问题排查

| 现象 | 可能原因与解决 |
|------|----------------|
| `[ERROR] 未检测到 MPU6050` | 检查 SDA/SCL 接线、VCC 供电、AD0 是否接地（地址 0x68）|
| `WHO_AM_I` 读出非 0x68 | 设备非 MPU6050（如 MPU9250/MPU6500），需确认芯片型号 |
| 数据全为 0 | I2C 接触不良或上拉电阻缺失（XIAO 板载一般已集成） |
| 陀螺仪漂移严重 | 未校准或校准时设备未静止，重新上电校准 |
| 串口无输出 | 确认串口监视器波特率为 115200；检查 USB 数据线是否支持数据传输 |
| 编译报错找不到 Wire.h | 确认已安装 ESP32 开发板核心并选择 XIAO ESP32C3 开发板 |

## 十一、校准注意事项

- 校准在每次上电时**自动执行**（约 2–3 秒），期间设备必须**静止平放**
- 校准会自动扣除陀螺仪零漂与加速度计偏移（含 Z 轴 1g 重力分量）
- 若使用场景的安装方向不同（如手环佩戴后 Z 轴非垂直），需相应调整校准姿态或修改 `calibrate()` 中的期望值
